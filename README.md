## 주로 해온 일

### 백엔드 개발
업무 시스템과 연계되는 API 서버 및 관리자 기능을 개발하고 유지보수했습니다.  
기능 구현뿐 아니라 구조를 단순하게 유지하고, 운영 중 장애가 나더라도 원인을 추적하기 쉬운 형태로 만드는 데 신경 써왔습니다.

### 배치 및 데이터 처리
정기 실행 배치, 파일 수집 및 가공, 데이터 적재 프로세스를 구현했습니다.  
실행 순서, 중복 처리, 재처리 가능 여부처럼 운영에서 중요한 부분을 고려해 안정적으로 동작하도록 설계했습니다.

### 데이터베이스 설계
서비스 목적에 맞게 테이블 구조를 설계하고, 인덱스와 제약조건을 적용해 데이터 정합성을 유지하는 작업을 해왔습니다.  
복잡한 조회나 적재 로직은 MyBatis와 SQL 중심으로 풀어내는 데 익숙합니다.

### 운영 및 배포
Linux 서버 환경에서 서비스 배포와 운영을 경험했습니다.  
Nginx 설정, 환경 분리, 로그 확인, 배포 흐름 정리 등 실제 운영에 필요한 작업을 함께 수행했습니다.
